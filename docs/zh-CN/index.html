为真实终端工作而设计

小而专注，认真处理终端。

一个 Rust 服务端和一个浏览器终端界面，目标不是网页表单，而是真正可用的终端体验。

⌘

持久 PTY 会话

刷新或重连后，五分钟内仍回到同一个 shell，不会丢失正在运行的进程。

↻

重连与回放

带序号的输出历史、明确的截断提示，以及带退避的重连机制。

⌁

Token 优先认证

URL fragment 引导、HttpOnly SameSite cookie、Host/Origin 校验和登录限流。

▣

浏览器终端

xterm.js 搜索、安全链接、复制粘贴、主题、字体大小和移动端特殊键。

◈

三个平台

Windows、Linux 二进制和 Android arm64 前台服务 APK。终端交互始终在浏览器中完成。

☁

开始使用

一个配置文件，一条命令。

下载发布包，复制 INI 示例，然后让服务只监听本机回环地址。

命令行参数会覆盖 INI 配置。默认端口为 7755；Android 在端口被占用时会回退到临时端口。

安全模型

默认只监听本机。

为可信反向代理或 VPN 部署设计，在每一个边界上采取明确策略。

01默认绑定 127.0.0.1:7755，并且强制 Token 认证。
02URL fragment 引导 HttpOnly、SameSite=Strict 会话 cookie。
03强制校验 Host/Origin，并限制 WebSocket 大小和超时。
04默认只读，只有显式传入 -W 才允许终端输入。
HTTPS 反向代理提醒
Cloudflare 或其他反向代理终止 TLS 时，必须使用 --secure-cookie。否则浏览器发送 HTTPS Origin，而服务端按 HTTP 校验，WebSocket 可能被拒绝。
